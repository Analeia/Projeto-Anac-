==============================================================================
GUIA RÁPIDO: CONFIGURAÇÃO DE AMBIENTE VIRTUAL (VENV)
==============================================================================

1. O QUE É O VENV?
Um ambiente virtual é um diretório isolado onde você instala apenas as bibliotecas
necessárias para este projeto, sem afetar o Python instalado no seu sistema operacional.

------------------------------------------------------------------------------
2. COMO CRIAR O AMBIENTE VIRTUAL
Abra o terminal na pasta do projeto e execute:

# Cria o ambiente virtual em uma pasta oculta chamada .venv
python3 -m venv .venv

------------------------------------------------------------------------------
3. COMO ATIVAR O AMBIENTE VIRTUAL

👉 NO macOS / Linux:
source .venv/bin/activate

👉 NO WINDOWS (PowerShell):
.venv\Scripts\Activate.ps1

👉 NO WINDOWS (CMD / Prompt de Comando):
.venv\Scripts\activate.bat

------------------------------------------------------------------------------
4. COMO SABER SE DEU CERTO?
O terminal mostrará "(.venv)" no início da linha de comando.
No Mac, você pode confirmar digitando:
which python
(o caminho exibido deverá terminar em ".venv/bin/python")

------------------------------------------------------------------------------
5. RESOLUÇÃO DE ERROS COMUNS:
- No Windows PowerShell, se aparecer erro de script desabilitado:
  Abra o PowerShell como Administrador e execute:
  Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

- No macOS, certifique-se de usar "python3" e "pip3" caso o comando "python" aponte
  para versões legadas.

------------------------------------------------------------------------------
6. ATUALIZAR O PIP E INSTALAR PACOTES BÁSICOS:
pip install --upgrade pip
pip install psycopg2-binary pandas openpyxl chardet ipykernel
